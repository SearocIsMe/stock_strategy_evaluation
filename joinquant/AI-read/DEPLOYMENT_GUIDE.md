## 六、紧急情况处理

### 6.1 黑天鹅事件应对

**Level 1：单日跌幅3-5%**
```
动作：观察，无需人工干预
策略：自动执行一级风控
```

**Level 2：单日跌幅5-8%**
```
动作：密切关注
策略：触发一级熔断，降仓至30-50%
人工：准备休市后复盘
```

**Level 3：单日跌幅>8%或连续暴跌**
```
动作：立即人工介入
策略：自动清仓
人工：
1. 确认清仓完成
2. 评估是否暂停策略
3. 等待市场稳定后重启
```

### 6.2 策略失效识别

**失效信号：**
1. 连续5个交易日跑输基准>2%
2. 单月回撤>7%
3. 胜率连续2周<50%

**应对措施：**
```
阶段1：降低仓位至50%
阶段2：暂停新开仓，仅持有+止损
阶段3：完全停止策略，人工接管
```

## 八、常见问题FAQ

### Q1：策略为什么持仓这么少？
**A**：策略追求高收益低回撤，集中持仓（2-8只）是为了：
- 提高单票收益贡献
- 便于风险监控
- 避免过度分散导致收益平庸

### Q2：为什么不满仓？
**A**：动态仓位管理是风控核心：
- 强势市场：80-90%仓位
- 中性市场：60-70%仓位
- 弱势市场：30-50%仓位
- 目标是"牛市吃肉，熊市保命"

### Q3：ETF轮动频率如何？
**A**：优化后的ETF轮动：
- 检测频率：每周一（非每日）
- 换仓条件：动量得分差异>15%
- 避免了过度交易

### Q4：如何处理停牌股票？
**A**：策略已内置处理：
- 选股时过滤停牌
- 卖出时跳过停牌（自动保留）
- 复牌后次日检查是否卖出

### Q5：小资金（<10万）能用吗？
**A**：可以，但需调整：
```python
g.aggressive_stock_num = 1  # 减少持股数
g.balanced_stock_num = 2
g.defensive_etf_num = 1
```
