## 根本原因分析

### Bug #1：无限递归（致命错误）

**位置：** [`optimized_strategy_v1.py`](optimized_strategy_v1.py:944)

```python
# ❌ 错误代码（第944-946行）
def initialize(context):
    """策略初始化入口"""
    initialize(context)  # 调用自己！无限递归！
```

**影响：** 导致策略初始化失败或陷入死循环

**修复：**
```python
# ✅ 删除重复的initialize定义
# JoinQuant只需要一个initialize函数
```

---

### Bug #2：择时系统过于复杂

**问题：**
- 多信号融合计算量大
- 初期数据不足导致信号无效
- 可能长期处于WEAK状态，不建仓

**证据：**
```python
# RSRS需要600天历史数据才生效
g.rsrs_params = {'N': 18, 'M': 600}

# 初期g.slope_series为空，导致RSRS返回'KEEP'
if len(g.slope_series) >= M:  # 需要600天！
    # 计算信号
```

**影响：** 回测初期（2020年）长期不交易，错过牛市

---

### Bug #3：选股条件过严

**问题：**
```python
# 过滤创业板+科创板+北交所
if stock.startswith('300') or stock.startswith('688')...
    continue
```

**影响：** 排除了大量优质小市值股票（创业板小市值是核心标的）

---

### Bug #4：仓位计算错误

**问题：**
```python
# 计算可用资金时未考虑已有持仓
available_value = max(0, target_value - current_value)

# 但买入时又除以所有需买数量
value_per_stock = available_value / len(buy_list)
```

**影响：** 可能导致资金分配不合理，无法建立完整仓位
