    test_date = '2024-08-05'

### 3.2 核心指标验证矩阵

#### A. 收益指标（必须满足）

| 指标 | 目标值 | 验证方法 | 通过标准 |
|-----|-------|---------|---------|
| 年化收益率 | ≥200% | 回测结果直接读取 | ✅ ≥180% |
| 累计收益率 | - | 总收益/初始资金 | 5年期≥1000% |
| 月度胜率 | ≥65% | 盈利月份/总月份 | ✅ ≥60% |
| 超额收益Alpha | ≥1.5 | 策略收益-基准收益 | ✅ ≥1.2 |

#### B. 风险指标（必须满足）

| 指标 | 目标值 | 验证方法 | 通过标准 |
|-----|-------|---------|---------|
| 最大回撤 | ≤10% | 回测曲线最低点 | ✅ ≤10% |
| 平均回撤 | ≤5% | 所有回撤均值 | ✅ ≤5% |
| 年化波动率 | - | 日收益率标准差×√252 | ≤35% |
| 下行波动率 | - | 仅计算负收益日 | ≤20% |

#### C. 风险调整收益（优秀标准）

| 指标 | 目标值 | 计算公式 | 通过标准 |
|-----|-------|---------|---------|
| 夏普比率 | ≥2.5 | (年化收益-无风险利率)/波动率 | ✅ ≥2.0 |
| 索提诺比率 | ≥3.0 | (年化收益-无风险利率)/下行波动率 | ✅ ≥2.5 |
| 卡玛比率 | ≥20 | 年化收益/最大回撤 | ✅ ≥18 |
| 信息比率 | ≥1.0 | 超额收益/跟踪误差 | ✅ ≥0.8 |

### 3.3 指标验证脚本

```python
# 在回测结束后运行
def validate_performance_metrics(backtest_id):
    """验证性能指标"""
    # 获取回测结果
    result = get_backtest(backtest_id)
    
    # 验证收益指标
    annual_return = result.returns.annual_return
    assert annual_return >= 1.80, f"年化收益{annual_return:.2%}低于目标"
    
    # 验证回撤
    max_drawdown = result.max_drawdown
    assert max_drawdown <= 0.10, f"最大回撤{max_drawdown:.2%}超过10%"
    
    # 验证夏普
    sharpe = result.sharpe
    assert sharpe >= 2.0, f"夏普比率{sharpe:.2f}低于2.0"
    
    # 验证Alpha
    alpha = result.alpha
    assert alpha >= 1.2, f"Alpha{alpha:.2f}低于1.2"
    
    print("✅ 性能指标验证全部通过")
    print(f"  年化收益: {annual_return:.2%}")
    print(f"  最大回撤: {max_drawdown:.2%}")
    print(f"  夏普比率: {sharpe:.2f}")
    print(f"  Alpha: {alpha:.2f}")
```

### 6.2 持仓集中度

**标准：**
```
单票最大仓位：≤30%
前3大持仓合计：≤65%
持仓数量范围：3-10只
```

**验证脚本：**
```python
def validate_position_concentration(positions):
    """验证持仓集中度"""
    total_value = sum(p['value'] for p in positions)
    
    # 单票最大仓位
    max_position = max(p['value'] / total_value for p in positions)
    assert max_position <= 0.30, f"单票仓位{max_position:.1%}过高"
    
    # 前3大持仓
    top3 = sorted(positions, key=lambda x: x['value'], reverse=True)[:3]
    top3_ratio = sum(p['value'] for p in top3) / total_value
    assert top3_ratio <= 0.65, f"前3大持仓{top3_ratio:.1%}过于集中"
    
    print("✅ 持仓集中度验证通过")
```

### 10.2 预警机制

**触发条件：**
1. 连续3日跑输基准 > 2%
2. 单周回撤 > 5%
3. 月度胜率 < 50%
4. 实盘与回测偏差 > 15%

- Level 1（预警）：增加监控频率
- Level 2（警告）：降低仓位至50%
