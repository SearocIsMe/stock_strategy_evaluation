## 🔍 失败根因分析

### 致命错误 #1：质量换数量 ❌

**v5的错误逻辑：**
```python
# v5 (line 46-50)
g.stock_num = 8              # 8只股票（过度分散）
g.min_market_cap = 5         # 5亿起（垃圾股区间）
g.max_market_cap = 150       # 扩大到150亿
g.max_stock_price = 150      # 150元（没意义的高价）

# 选股条件（line 268-277）
income.net_profit > 0        # 仅要求盈利（过于宽松！）
# 没有ROE、营收等质量要求！
```

**v2的正确做法：**
```python
# v2稳健参数
g.stock_num = 4              # 4只精选
g.min_market_cap = 10        # 10亿起（避免超小盘垃圾）
g.max_market_cap = 100       # 100亿（小市值甜蜜区）
g.max_stock_price = 50       # 50元（避免高价股）

# 质量筛选
income.net_profit > 0
indicator.roe > 0            # 要求ROE>0（盈利质量）
income.operating_revenue > 1e8  # 营收>1亿
```

**问题：**
- 5-10亿市值区间是"垃圾股重灾区"
- 8只分散持股 = 单只仓位10.6%（85%/8），好股赚钱少，差股拖累多
- 无ROE要求 = 选到高负债、低质量盈利公司

**实际影响：**
- 选股池从优质扩大到低质
- 持有8只，其中5-6只是平庸或亏损标的
- 少数优质股收益被差股抵消

### 致命错误 #2：风控失效 ❌

**v5的松懈风控：**

**v2的严格风控：**

**问题：**
1. **12%止损** = 单只股票可以亏更多（-12% × 10.6%仓位 = -1.27%损失）
2. **300%止盈** = 小市值很难3倍，导致利润无法兑现
3. **6%指数熔断** = 反应太慢，跌5%时已经损失惨重

**实际影响：**
- 亏损股容忍度过高，累积大量浮亏
- 盈利股无法及时止盈（等待3倍太久）
- 指数暴跌时保护不及时

### 致命错误 #4：交易成本 ❌

**v5的交易问题：**

**成本估算：**
```
8只股票 × 每周调仓 × 可能换手
```

**加上：**
- 低质股票波动大 → 触发止损频繁
- 8只分散 → 调整频繁

**v2交易更少：**

- 每周调仓但换手少（质量稳定）

## 🎯 核心教训

### 1. 质量 > 数量

**错误观念：**
> "更多股票 = 更多机会"

**真相：**
> 8只低质股 < 4只优质股

**数学：**
```
v5: 8只股票，假设4只+10%，4只-10%
= (4×10% - 4×10%) / 8 = 0%

v2: 4只优质股，假设3只+40%，1只-9%（止损）
= (3×40% - 1×9%) / 4 = 27.75%
```

### 2. 严格风控 > 激进仓位

**错误观念：**
> "85%仓位 = 更高收益"

**真相：**
> 85% × 低质 = 巨亏
> 60% × 高质 = 稳赚

### 3. 小市值≠超小盘

**市值分层：**
```
0-5亿：   垃圾股、壳资源
5-10亿：  高风险小盘（v5区间）❌
10-50亿： 成长小盘（v2甜蜜区）✅
50-100亿：小市值龙头（v2上限）
100-150亿：中小盘（v5扩大）
```

### 4. 止盈要现实

**v5: 300%止盈**
- 小市值3倍需要多久？可能1-2年
- 期间回撤、调仓早已卖出
- 实际永远达不到

**v2: 150%止盈**
- 小市值1.5倍更常见
- 半年内可达成
- 及时锁定利润
